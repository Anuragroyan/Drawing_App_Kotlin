🎨 Kids Drawing Board

Kids Drawing Board is a Java-based Android drawing application designed to provide children with a simple and interactive digital canvas for creative drawing. The application is built using XML layouts and Android drawing APIs, with drawable resources used to create intuitive controls for different drawing features.

Users can select colors from a palette, adjust brush stroke sizes, draw freely on the canvas, and modify their artwork using undo and redo actions. Once the drawing is complete, users can download and save their artwork for later use.

✨ Features

* 🎨 Color Palette – Choose different colors for drawing.
* 🖌️ Brush Customization – Select different brush stroke sizes.
* ✏️ Drawing Canvas – Draw freely using touch interaction.
* ↩️ Undo – Remove the most recent drawing action.
* ↪️ Redo – Restore a previously undone action.
* 🧹 Clear Canvas – Remove the drawing and start again.
* 💾 Download Drawing – Save the completed artwork.
* 🖼️ Drawable Resources – Custom drawable files for feature icons and controls.
* 📱 Child-Friendly UI – Simple controls designed for easy interaction.
* ⚡ Real-Time Drawing – Display drawing strokes directly on the canvas.

🎯 Project Purpose

The project demonstrates how to build an interactive drawing application for Android using Java and XML. It focuses on touch-based drawing, canvas manipulation, brush customization, color selection, undo/redo functionality, resource management, and saving user-created artwork.
